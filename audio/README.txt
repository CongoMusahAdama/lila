Drop your nasheed mp3 files in this folder.

Then open ../config.js and add one line per song inside the `nasheeds` array, for example:

  { src: "audio/maher-zain-ya-nabi.mp3", title: "Maher Zain — Ya Nabi Salam Alayka" },

The site will automatically list them in the Nasheeds tab with a working player.
